# Third Orbit Ltd.

A WebGL background animation of three-body periodic orbits. All TypeScript —
the renderer, the orbit precompute, and the build glue.

## Project layout

```text
.github/workflows/deploy.yml   GitHub Pages deploy on push to main
scripts/
  precompute.ts                Adaptive DP54 integrator → orbit bins + JSON
  init_conditions.json         The 15 known periodic orbits
  fetch-font.mjs               Downloads Unica One into src/public/fonts/
src/                        Vite root (source)
  index.html
  3body.ts                     The renderer
  public/                      Vite publicDir — copied as-is during build
    fonts/                     ← downloaded by fetch-font.mjs (gitignored)
    orbits/, orbits.json       ← generated by precompute.ts (gitignored)
package.json                   Vite 8 (Rolldown) + tsx + TypeScript
```

## Local development

```bash
npm install
npm run setup    # downloads font + generates orbit bins (~1s)
npm run dev      # http://localhost:5173
```

`npm run build` re-runs `setup` automatically and produces `dist/`.

## How the precompute works

`scripts/precompute.ts` implements a Dormand-Prince 5(4) ODE integrator with
adaptive step size and FSAL — the same method scipy's `RK45` uses, just
written by hand so we don't need a Python toolchain. For each periodic
orbit it integrates from `t=0` to `T`, samples the trajectory on a uniform
time grid via cubic Hermite interpolation, and writes a packed float32
binary plus metadata. The browser fetches just the one orbit it picks on
load.

Periodicity seams (||y(T) − y(0)|| / max extent) are reported during the
run; they're a quality check on the published initial conditions, not the
integrator.

## Deployment

Pushing to `main` triggers the GitHub Pages workflow: install Node, run
`npm run build`, upload `dist/`. Set the Pages source to "GitHub Actions"
in the repo settings to enable.
