# Third Orbit Ltd.

A WebGL background animation of three-body periodic orbits.

## Project layout

```
.github/workflows/deploy.yml   GitHub Pages deploy on push to main
precompute/                    Python script that integrates the orbits
  precompute.py
  init_conditions.json         The 15 known periodic orbits
  requirements.txt
scripts/
  fetch-font.mjs               Downloads Unica One into static/public/fonts/
static/                        Vite root (source)
  index.html
  3body.ts                     The renderer
  public/                      Vite publicDir — copied as-is during build
    fonts/                     ← downloaded by fetch-font.mjs (gitignored)
    orbits/, orbits.json       ← generated by precompute.py (gitignored)
package.json                   Vite + TypeScript + rolldown-vite
```

## Local development

One-time setup:

```bash
npm install
pip install -r precompute/requirements.txt
npm run setup    # downloads font + generates orbit bins
```

Then:

```bash
npm run dev      # http://localhost:5173
npm run build    # production build into dist/
npm run preview  # serve the production build
```

`npm run build` re-runs `setup` automatically, so CI doesn't need a separate step.

## Deployment

Pushing to `main` triggers the GitHub Pages workflow. It installs Python and
Node, runs the precompute step, downloads the font, builds with Vite, and
publishes `dist/` to GitHub Pages.

To enable: in repo settings, set Pages source to "GitHub Actions".
